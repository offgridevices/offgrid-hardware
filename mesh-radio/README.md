# Mesh Radio (working name)

A single-board LoRa mesh radio with Bluetooth, built only from parts that a
US or allied assembler can source and build. It replaces the RAK WisBlock
(RAK4631 on a RAK19003) in OffGrid's mesh nodes, starting with Cairn
(formerly Project Cheap Drone Phase 2). Runs Meshtastic; MeshCore later.

The name is a placeholder until the owner picks one before the first order.
